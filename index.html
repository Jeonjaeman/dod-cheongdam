01 · 지켜야 할 가치

다시 만드는 이유보다,
먼저 지켜야 할 가치

현재 홈페이지는 아임웹을 활용해 병원 공간의 분위기와 의료진, 다양한 시술 콘텐츠를 정성껏 담았습니다. 이 콘텐츠와 디자인 자산은 검수 후 최대한 보존·이전하고, 홈페이지와 관리시스템은 병원 업무에 맞춰 새로 구축하는 방향을 제안드립니다.

전문의 중심의 진료 소개

의료진의 경력과 진료 접근법이 병원을 선택하는 이유가 됩니다. 장비 소개와 함께 어떤 의료진이 어떻게 상담하고 진료하는지 더 명료하게 연결하겠습니다.

프라이빗한 경험

홈페이지가 소개하는 1인 시술실·회복 케어·진단 과정은 가격 외의 선택 이유입니다. 실제 방문 전 환자가 경험의 순서를 이해하도록 구성하겠습니다.

리프팅·부스터·재생의학이라는 세 축

현재 홈페이지는 재생 중심 안티에이징을 명확히 내세웁니다. 이 정체성을 유지하면서, 여러 장비와 프로그램 중 자신이 무엇을 상담하면 좋을지 찾는 길을 보완하겠습니다.

이미 축적한 콘텐츠

시술 설명·FAQ·의료진 해설·외국어 안내는 중요한 자산입니다. 재사용 권한과 의학적 표현을 검토하고, 필요한 부분만 보완해 이전합니다.

02 · 개선할 점

부족한 것은 정성이 아니라,
정보를 연결하고 관리하는 규칙입니다

공개 홈페이지에서 확인한 내용을 현재 모습과 개선 방향으로 나누어 정리했습니다.

현재

장비 이름을 모르는 환자도 길을 찾을 수 있어야 합니다

메뉴는 시술·장비별로 상세하게 구성되어 있습니다. 이미 시술을 정한 환자에게는 유용하지만, ‘탄력이 떨어졌어요’처럼 고민만 가진 환자에게는 선택 과정이 필요합니다.

개선

기존 시술 페이지는 유지하면서 처짐·탄력 / 피부결·볼륨 / 색소 / 모공·흉터 등 고민별 입구를 더합니다. 고민별 안내는 진단을 대신하지 않고, 의료진에게 무엇을 상담할지 돕는 역할로 설계합니다.

현재

이벤트는 보입니다. 다만 조건을 비교하고 관리하기 어렵습니다

이벤트 페이지에는 이미지 카드 8개가 표시됩니다. 첫방문·요일·장비 도입·웨딩 등 다양한 제안이 이미 준비돼 있습니다. 다만 이미지 중심이어서 진행 기간·대상·가격 조건을 글자로 읽고 비교하기 어렵고, 확인한 카드의 이미지 대체 설명도 비어 있습니다.

개선

이미지 디자인은 유지하고 제목·기간·대상·가격과 적용 조건을 실제 글자로 제공합니다. 진행 중·예정·종료를 구분하고, 이벤트에서 해당 시술 설명과 상담으로 이어지도록 연결합니다.

현재

시술마다 정보의 형식이 같아지면 신뢰가 쌓입니다

써마지 페이지에서는 여러 문구가 모두 큰 제목(H1)으로 지정되어 있고, 설명 문구는 키워드 나열 형태입니다. 병원 정보와 함께 배송·반품 같은 상점용 구조화 정보도 출력됩니다. 병원에 맞게 정보 위계와 설정을 정리할 여지가 있다는 뜻이며, 특정 검색 순위 하락의 원인으로 단정하는 것은 아닙니다.

개선

시술마다 요약·원리·선택 기준·진료 과정·주의사항·비용 조건·FAQ·감수자와 수정일을 같은 틀로 제공합니다. 화면과 검색용 정보가 같은 내용을 담도록 정리합니다.

현재

작은 연결 오류부터 바로잡겠습니다

확인 당시 하단 비급여수가표 링크에는 실제 목적지 대신 ‘이미지주소’라는 문자열이 들어 있었습니다. 화면과 구조화 정보의 이메일도 다르게 표기되어 있어 대표 안내 기준을 확인할 필요가 있습니다.

개선

승인된 수가표·연락처·진료시간의 기준 자료를 정하고, 화면·상담 안내·외부 채널에 일관되게 반영합니다. 이메일은 둘 다 유효할 수 있으므로 오류로 단정하지 않고 용도를 확인합니다.

03 · 규격화된 리뉴얼

규격화된 리뉴얼이 먼저입니다

규격화는 모든 병원을 같은 디자인으로 만든다는 뜻이 아닙니다. 디오디의 디자인과 진료 개성은 유지하면서, 바뀌는 정보의 입력·승인·게시·수정 방식에 일정한 규칙을 만드는 일입니다.

입력정해진 항목으로승인의료진·담당자 확인게시여러 화면에 일관되게수정변경 기록과 함께

홈페이지의 새로운 흐름

  1. 홈병원의 핵심 소개 → 진료 세 축 → 전문의·진단·프라이빗 과정 → 고민별 안내 → 대표 프로그램·이벤트 → 상담·방문 안내
  2. 고민별 진료무엇이 고민인지 선택하고 관련 진료와 상담 기준을 이해합니다.
  3. 시술·장비기존 상세 설명을 살리되 공통 템플릿으로 비교·이해하기 쉽게 만듭니다.
  4. 재생의학 센터의료진·연구·기관 지정 근거를 소개하고, 연구 결과와 실제 제공 진료의 범위·한계를 명료하게 구분합니다.
  5. 이벤트·프로그램현재 이용 가능한 제안과 조건을 확인합니다.
  6. 의료진 해설·FAQ시술 전 궁금증을 풀고 상담할 질문을 정리합니다.
  7. 방문·외국인 안내진료시간·주차·상담 언어·예약 경로를 확인합니다.

05 · 병원 맞춤 자체 제작

디오디의 운영에 맞춘 홈페이지와
관리시스템을 직접 구축합니다

기존 홈페이지는 아임웹으로 병원의 분위기와 콘텐츠를 정성껏 구현해 왔습니다. 앞으로는 그 자산을 살리면서, 범용 플랫폼의 틀과 설정에 병원 업무를 맞추기보다 디오디의 진료 안내와 콘텐츠 운영에 맞춘 자체 제작 홈페이지·관리시스템을 제안드립니다.

단순히 디자인을 새로 입히는 작업이 아닙니다. 시술·의료진·이벤트·다국어 정보를 각각 관리할 수 있는 콘텐츠로 설계하고, 한 번 승인한 정보가 여러 화면에 일관되게 반영되도록 구축합니다. 검색용 정보와 접근 정책도 운영 주체가 점검·관리할 수 있는 구조를 설계합니다.

한 번 수정해 여러 화면에 반영

시술·의료진·장비·이벤트의 기준 정보를 한곳에서 관리합니다. 변경된 내용이 홈페이지 목록·상세·관련 배너에 연결되어, 같은 정보를 화면마다 따로 고치는 부담을 줄입니다.

병원 업무에 맞춘 승인과 일정 관리

작성 → 의료진·담당자 검토 → 승인 → 예약 게시 → 종료의 흐름을 설계합니다. 이벤트 기간과 상태, 변경 이력을 관리하고, 언어별 반영 여부도 확인할 수 있도록 합니다.

환자 안내와 검색 정보를 같은 원본에서

환자가 읽는 설명과 병원·의료진·시술 구조화 정보가 같은 기준 자료에서 나오도록 구성합니다. 임의의 중복 설명이나 병원과 무관한 상점 정보를 줄이고, 수정 시 함께 점검할 수 있게 합니다.

제작 이후의 운영까지 포함한 설계

담당 직원이 실제 이벤트를 수정하고 승인·게시·종료하는 흐름을 기준으로 관리 화면을 설계합니다. 역할별 접근권한, 변경 기록, 백업·복구와 유지관리 책임도 구축 범위에 맞춰 정합니다.
